Instant Theme Switching

Experience seamless color transitions. Click the sliding toggle in the navigation bar to switch between the vibrant light and deep dark themes. Your selection is automatically saved to your browser.

Smooth Transitions

Every color updates instantly when the HTML data-theme attribute changes. CSS transition handles the 0.4s ease effect automatically across all elements.

OS Preference Auto-Detect

By default, we detect your operating system's color scheme using prefers-color-scheme. You can override it manually and we'll remember your choice.

Fully Accessible

The toggle is fully keyboard accessible, features a visible focus ring, and properly uses aria-label and aria-live to announce the current state to screen readers.
